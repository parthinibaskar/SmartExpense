# SmartExpense

SmartExpense is a simple web application for managing daily income and expenses.

## Features
* Signup and Login
* Add income and expenses
* View total income, expenses and balance
* View transactions
* Check spending analytics
* Set budget
* Dark mode
* Logout

## Technologies Used
* HTML
* CSS
* JavaScript
* Local Storage

## Pages
* Login
* Signup
* Dashboard
* Budget
* Transactions
* Analytics

## How to Use
1. Create an account using the Signup page.
2. Login using your email and password.
3. Add your income and expenses from the Dashboard.
4. View your transactions and spending analytics.
5. Set your budget and manage your expenses.
